TimeBubble - Privacy Policy

Last updated: September 15, 2026

Summary: TimeBubble does not collect, store, or transmit any personal data. All processing happens locally in your browser.

1. Overview

TimeBubble ("the Extension") is a browser extension that displays YouTube comment timestamps as floating speech bubbles on the video player. This Privacy Policy explains what data the Extension accesses, how it is used, and your rights.

2. Data Collection

TimeBubble does not collect any personal data. Specifically, the Extension:

  • Does not collect names, email addresses, or any personally identifiable information.
  • Does not collect browsing history.
  • Does not collect financial or payment information.
  • Does not collect health, authentication, or communications data.
  • Does not transmit any data to external servers operated by the developer.

3. Local Storage

The Extension uses the browser built-in storage.sync / storage.local APIs solely to save your personal preferences (e.g., bubble position, display settings). This data:

  • Remains exclusively in your browser / browser account sync.
  • Is never sent to any third-party server.
  • Can be deleted at any time by removing the Extension.

4. Permissions Used

  • activeTab / tabs - Required to detect the currently active YouTube tab and inject the overlay UI.
  • scripting - Required to run the content script that renders comment bubbles on the page.
  • storage - Required to persist user preferences locally.
  • Host permission (*://*.youtube.com/*) - Required to access YouTube pages where the Extension operates.

No permission is used to collect or exfiltrate user data.

5. Third-Party Services

TimeBubble fetches publicly available YouTube comment data directly from YouTube pages. No data is routed through any developer-controlled proxy or third-party analytics service.

6. Remote Code

TimeBubble does not load or execute any remote code. All extension code is bundled and reviewed at install time.

7. Children Privacy

The Extension does not knowingly collect data from children under 13, because it does not collect data from anyone.

8. Changes to This Policy

If this policy changes in a future version, the updated date at the top of this page will reflect the change.

9. Contact

If you have questions about this Privacy Policy, please open an issue on the TimeBubble GitHub repository.
